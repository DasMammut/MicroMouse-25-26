# Micromouse Projekt 🐭

Ein kompakter autonomer Roboter, der entwickelt wurde, um ein Labyrinth eigenständig zu erkunden und den schnellsten Weg zum Ziel zu finden.

## 🛠 Hardware
* **Mikrocontroller:** [z.B. STM32 / Arduino / ESP32 eintragen]
* **Antrieb:** [z.B. N20 Micro-Getriebemotoren mit Encodern]
* **Sensoren:** [z.B. Infrarot-Distanzsensoren / Time-of-Flight]
* **Chassis:** [z.B. 3D-gedrucktes Custom-Design]

## 💻 Software
* **Programmiersprache:** C / C++
* **Navigation:** Flood-Fill Algorithmus zur Pfadfindung
* **Regelung:** PID-Regler für stabile Geradeausfahrt und exakte Drehungen
